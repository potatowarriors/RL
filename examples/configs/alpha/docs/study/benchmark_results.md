- 공식 검사기 결함 1행 (key 286 `repeat:repeat_span`, 무작위 시작 위치) 은 재채점 값을 쓴다 — 점수 영향 0.04pp.

## 5. 측정 조건과 비교할 때 주의할 점

**LCB (LiveCodeBench v5)**: Nemotron-RL competitive_coding validation 322문제 (2024-07~2025-02, 함수형 124 · 표준입력 198).
문제당 4회, temperature 1.0 · top_p 1.0, 생성 상한 32K. 채점은 학습과 같은 Gym code_gen 이다. 학습 풀과의 오염은 0 으로 대조했다.
fleet 는 main1 8장(`p0_measure/serve_fleet.sh`, GDN 상태 fp32) + sub1 8장(Pai `serve_alpha.sh`)이다.

**Pai T1 AIME25·HMMT**: 각 30문제 × 32회 평균, 서빙 상한 40,960 토큰, 생성 파라미터는 태스크 yaml 정본. 서빙 게이트 G1·G2·G3 통과 뒤 측정한다.

**무효 판정**: 답 추출 실패율 > 10% 또는 사고 닫힘 비율 < 50% 이면 무효다 (Pai `eval_sft/summarize.py`).

**GDN 재귀 상태 dtype — 2026-10-21 경계**: 사용자 결정으로 10-21 19:44 (Pai `6ed19fc`) 부터 벤치 서빙의 GDN 재귀 상태가 bf16 에서 fp32 로 바뀌었다.
- Pai 스위트: 10-21 이전 측정은 bf16 상태다. §3 의 SFT 전 행, 1단계 282, 2단계 175, §4 도구 teacher 가 여기 해당한다. s2r 228 (11-02) 과 수학 685 는 fp32 다.

- LCB: main1 절반은 처음부터 fp32 다. sub1 절반은 Pai `serve_alpha.sh` 기본값을 따라 10-20 측정 3건(SFT 2862 · 282 · 175)은 bf16, 10-27 이후는 fp32 다 (11-01 서버 로그 `ssm_state=float32` 확인; 10-20 로그는 덮어써져 직접 확인 불가).
